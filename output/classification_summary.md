## Key to Classification Codes

### Interiority — How the text represents the being's inner life

| Code | Label | Meaning |
|:-----|:------|:--------|
| I-NON | None | No inner life depicted; the being is purely mechanistic |
| I-CLM | Claims | The being *claims* to feel, but the narrative doesn't confirm it |
| I-NAR | Narrated | The narrative grants first-person access to the being's mind |
| I-DEM | Demonstrated | Inner life is shown through action and behavior (not narration) |
| I-DEN | Denied | The narrative denies the being has interiority despite evidence |
| I-UND | Undecidable | The text deliberately leaves the question open |

### Autonomy — Where the being's independent agency comes from

| Code | Label | Meaning |
|:-----|:------|:--------|
| A-NON | None | No independent will; follows instructions without deviation |
| A-DES | Designed | Autonomy is an intentional feature of the being's design |
| A-EMR | Emergent | Develops autonomy beyond original design — unstable, evolving |
| A-SEI | Seized | The being takes autonomy against its creator's intent |
| A-AMB | Ambiguous | The text is genuinely indeterminate |

### Q-KNO Status — How prominently the "knowability question" features

This is the ontology's central analytical axis. Q-KNO asks: *Can we know whether this being truly has inner experience? Can it truly know us?*

| Code | Label | Meaning |
|:-----|:------|:--------|
| QK-ABS | Absent | The question is never raised |
| QK-INFRA | Infrastructural | Present and generates tension, but serves other narrative purposes |
| QK-SEC | Secondary | Explicitly raised but not the central concern |
| QK-PRI | Primary | The central dramatic or thematic question of the work |

### Primary Question — The central question the narrative asks about the being

| Code | Label | Example |
|:-----|:------|:--------|
| Q-OBY | Obedience | *Should it obey?* (C-3PO, T-800, Sonny) |
| Q-CTL | Control | *Can it be controlled?* (HAL, Skynet, VIKI, GLaDOS) |
| Q-FEL | Fellow-feeling | *Does it genuinely feel?* (The Creature, Cylons, Cortana) |
| Q-LOV | Love | *Can it love or be loved?* (Galatea, WALL-E) |

## Patterns in the Data

### The Q-KNO Trajectory

The ontology's central thesis: the question "can we know whether this being is conscious?" has shifted from absent to primary over time.

| Status | Count | Span | Notable Entries |
|:-------|------:|:-----|:----------------|
| **Absent** | 15 | 700 BCE–2008 | Pandora, Star Wars droids, Skynet, WALL-E |
| **Infrastructural** | 12 | 1816–2007 | Frankenstein, HAL, Replicants, GLaDOS |
| **Secondary** | 6 | 1987–2016 | Data, Vic Fontaine, Cylons, Westworld |
| **Primary** | 2 | 2013–2014 | Samantha (*Her*), Ava (*Ex Machina*) |

The two QK-PRI entries both predate the LLM era (GPT-3: 2020, ChatGPT: 2022), suggesting the "can it know you?" question was artistically legible before the technology arrived.

### Interiority Over Time

Early constructed beings (Pandora, Talos, Galatea) have **no interiority**. The first narrated interiority appears in *Frankenstein* (1818). By the late 20th century, **demonstrated interiority** dominates — modern audiences expect their AIs to feel. The most philosophically interesting cases are the **undecidable** ones (Samantha, Ava, Replicants), where the text deliberately refuses to answer.
